# KEMO Steels

A modern business website for **KEMO Steels**, built to present the company's steel-related products and business information online.

## Live Website

**[https://kemosteels.com/](https://kemosteels.com/)**

## Project Overview

The project focuses on creating a clear, responsive web presence for a steel business, making company and product information easy for visitors to explore.

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS

## Project Scope

- Frontend website development
- Responsive page layouts
- Business and product information presentation
- Website deployment

## About This Repository

This is a **portfolio repository** containing project information only. It does not contain the original website source code, client assets, credentials, or deployment configuration.
